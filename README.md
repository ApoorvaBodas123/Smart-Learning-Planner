# Roadmint - AI Learning Planner 🚀

Roadmint is a premium, distraction-free SaaS application designed to help you master new skills. It uses AI to generate personalized learning roadmaps, curates high-quality YouTube resources, and provides an isolated, highly-focused daily schedule so you can concentrate on one goal at a time.

## 🌟 Features
- **Roadmint Generator**: Generate detailed learning roadmaps with specific durations (e.g., 4 months) and starting skill levels.
- **Isolated Scheduling**: Focus entirely on a single active goal without interference from other roadmaps.
- **Mastery Calendar**: A dedicated monthly grid view to visualize your progress.
- **Deep Indigo UI**: A sleek, high-contrast, premium dark/light mode interface.
- **Smart Resource Matching**: Auto-generates robust YouTube search queries to ensure valid, up-to-date tutorials.

## 🛠️ Tech Stack
- **Frontend**: React, TypeScript, Tailwind CSS, Framer Motion
- **Backend**: FastAPI, Python, SQLAlchemy, PostgreSQL (Neon)
- **AI Engine**: Groq (Llama-3.3)
- **Security**: JWT Authentication, Bcrypt Hashing
